- **Spatial recognition — persistent occupancy map (fixed "stuck on a barrel").** The old `Navigator` only reacted to a position stall and cleared ALL blocked directions the instant it moved one step, so after sidestepping a barrel it aimed straight back into it and oscillated. New `src/agents/spatial.py` `SpatialMap`: a world-coordinate occupancy memory quantized to `CELL=16` units. A push that produces no RAM-position change records a **directional wall** `(cell_x, cell_y, dir)` ("from around here, going RIGHT is walled"); positions reached are marked free; capped at `MAX_WALLS=600` (LRU-evicted). The map **persists across directives** (a barrel does not move) — `Navigator.reset()` keeps it and only clears per-run detour state. `Navigator` rewritten as a committed wall-follower: when a desired direction is walled it picks one perpendicular detour and **stays committed until the blocked heading genuinely reopens**, re-probing that heading *purely* (not diagonally) to confirm it is past the obstacle — this kills the cross-axis bounce that undid the detour. Zero tokens. Verified with a simulated-world harness: single barrel, 2-wide crate block, long wall, wall-open-north/south, horizontal barrel, and an L-shaped trap all route to target (16–46 ticks). Executor reason now shows `(around wall)` when wall-following; `SpatialMap.summary()` exposes walls-here/mapped counts for display.

- **Feedback loop + no-feedback penalty + inert memory + image upscale (fixed "hung mashing Y at a window").** The AI mistook a window for a door and repeatedly walked-into-it + pressed Y forever, because the code `interact` primitive had no feedback check and `P_STUCK` never fired (the facing-nudge jitters position, so the reward tracker saw "moved +0.1"). Fix, in three reinforcing layers:
  - **Immediate feedback detector (orchestrator):** each tick computes a kind-aware state signature — for `interact`, position jitter is NOT feedback, only a dialogue/text box opening (`in_conversation` / `_dialogue_sig` change) counts; otherwise position matters. If a tick pressed buttons but the signature didn't move for `NOFEEDBACK_TICKS=3`, it fires a `no-feedback` replan and hands the Planner a `trouble` note: *"your directive produced NO change after N attempts … do something DIFFERENT, do not repeat it."* `src/agents/planner.py` injects it as a ⚠ line.
  - **Penalty (the user's idea, the slow/learning half):** `reward.py` `P_NO_FEEDBACK=-1.0`, applied on the no-feedback tick so the Reflector learns "stop repeating dead actions" as a lesson. The reward system feeds the Reflector every 15 ticks, so a penalty alone can't stop a live loop — hence it's paired with the immediate detector above.
  - **Inert-spot memory (spatial):** `SpatialMap.mark_inert/is_inert/nearby_inert` records "facing DIR from this cell did nothing" (LRU-capped like walls). The Planner is warned about inert directions at the current cell even on later visits, so it won't re-target the same window.
  - **See-better:** `tools/watch.py` `AI_OBS_SCALE=2` upscales the frame sent to the model (nearest-neighbor) so small sprites (door vs window, items) are legible — reduces the misidentification rate at the source. Vision will still err sometimes; the feedback loop is the guaranteed recovery. Verified end-to-end: an interact-with-non-interactable loop triggers a replan at tick 5, penalizes (−0.9), and marks the direction inert.

Slow thinks now hide under the current move; code (Navigator) ticks stay smooth.
